01

圧倒的な出会い

全国から集まる挑戦者たち。起業を目指す人、SNSで発信している人、海外挑戦したい人、将来本気で何かを成し遂げたい人。普通に生きていたら出会えない仲間と繋がれる。

02

海外という非日常環境

環境が変われば、人は変わる。日本を離れ、新しい価値観・文化・人に触れることで、人生の視野が一気に広がる。

Why ANZAS

最高な環境下での英語学習

ANZAS ならではの3つの魅力。

04

校舎はセブ島屈指の商業施設

フィリピン政府から認可のおりている安心と安全が確保された学校。商業施設の中に位置し、日本食レストランやスーパーマーケットなどが至近で利用できます。美味しい食事や必要なものが手の届く距離にあることは、セブでの滞在を一層魅力的にします。

05

完全マンツーマンレッスン

英語授業は、完全なマンツーマンレッスンです。ひとりひとりの生徒のレベルと目的にあわせ、効果的な学習をサポートします。短期間の留学であっても圧倒的な発話量を実現。短期間でも英語の伸びを実感できる。

06

一生忘れないボランティアプログラム

ANZASのボランティアプログラムはフィリピン政府とタッグを組んで行っている。貧困の格差を目の当たりにし、国際的な価値観を身につける。プログラム終了後はフィリピン政府から証明書も発行される。

Activity × Career

遊びじゃない、
ガクチカが生まれる現場。

5つの主要アクティビティそれぞれが、就活・キャリアに直結する具体的なメリットを生みます。

ACTIVITY 01

スラム街ボランティア

Key Point

たった半日で、自分の常識が覆る体験。

日本の日常では見えない現実を知り、自分が何のために挑戦するのかを突きつける。

何をやるのか / なぜやるのか

フィリピンのスラム地域を訪問し、子どもたちとの交流や直接的な支援活動を行います。綺麗事ではない社会課題を実際に自分の目で見ることで、当事者意識を養います。

就活・キャリアに直結！

ガクチカの独自性100%へ

アルバイトやサークルといった「ありきたりなエピソード」から完全に差別化。面接官の記憶に強烈に残る唯一無二の経験になります。

企業が求める「主体性」の獲得

経団連調査で企業が選考時に最重視する要素第1位の「主体性」。サステナビリティ(ESG/SDGs)の最前線に触れた経験は、大手・グローバル企業の評価を圧倒的に高めます。

ACTIVITY 02

現地での運動会

Key Point

英語が話せなくても大丈夫。

身体を動かし、「伝わった！」という成功体験が、海外への心理的ハードルをゼロにする。

何をやるのか / なぜやるのか

現地の学生とチームを組み、スポーツイベント（運動会）を企画・実施。言葉の壁や文化の違いを超えた、五感を使うコミュニケーションを体感します。

就活・キャリアに直結！

「真のコミュニケーション能力」の証明

採用担当者が最も重視する「多様な背景を持つ人を巻き込む力（社会人基礎力）」が身につきます。単なる「聞き上手」ではなく、「言葉の通じない相手と信頼関係を築き、イベントを成功させた」というエピソードは、面接での説得力を劇的に跳ね上げます。

ACTIVITY 03

現地大学生との交流会

Key Point

「海外の学生は、今何を考えているのか？」

同世代とのリアルな対話を通じて、自分の未来の可能性を限界突破する。

何をやるのか / なぜやるのか

フィリピンのトップクラスの大学生と少人数グループでディスカッション。同世代が持つ熱い価値観や人生観に触れ、自分の枠組みを広げます。

就活・キャリアに直結！

20代の市場価値を高める「グローバル視点」

英語への抵抗感をなくし、日本国内に閉じこもらないキャリアへの切符を手にします。

将来の選択肢が世界レベルへ広がる

グローバルな視野を持つ人材は、そうでない人材に比べ「20代の平均年収が高い」というデータも。生涯年収を左右する視座の高さが手に入ります。

ACTIVITY 04

ビジネスコンテスト

Key Point

アイデアを考えるだけで終わらせない。

限られた時間の中でリアルな課題解決案を形にし、実際に最前線を走る経営者達に提案する事で実践的なビジネスの厳しさと楽しさを知る。

何をやるのか / なぜやるのか

チームで課題に対する解決策を立案し、全員の前でプレゼン。挑戦する力と、それをやり切る実行力を徹底的に鍛えます。

優勝チームには 賞金・豪華商品 あり！

就活・キャリアに直結！

選考の難関「グループディスカッション(GD)」通過率の向上

企業の採用選考の8割以上で導入されるGD。このビジコンで「論理的思考力」「時間内に出すアウトプット力」を鍛えることで、就活本番のGDを難なく突破できるようになります。

圧倒的なプレゼン力・チームワークの体得

実社会で即戦力として求められる「正解のない問いに対して、チームで成果を出す力」が身につきます。

ACTIVITY 05

食事会 ＆ マリンアクティビティ

Key Point

「挑戦」の先にある「最高の思い出」と「一生モノの仲間」。

非日常の体験が、これからの人生を動かす強力な原動力になる。

何をやるのか / なぜやるのか

参加者や主催メンバーとの深い交流会、そしてセブの美しい海でのマリンスポーツを体験。過酷な挑戦だけでなく、海外の魅力を全力で楽しみ、人生の豊かさを学びます。

就活・キャリアに直結！

第一志望の内定率を高める「ピア効果（同期ネットワーク）」

同じ熱量で海外に挑んだ仲間との繋がりを持つ学生は、1人で活動する学生に比べて「第一志望群への内定率が約1.5倍高い」傾向があります。

帰国後も続く、人生の資産（人脈）

帰国後も参加者と繋がれるコミュニティを作成予定です。プログラム終了後も就活の情報交換やビジネスパートナーとして、生涯続く「かけがえのない横の繋がり」が手に入ります。

最大の特徴は「病院に行かずに、自宅にいながら本格的な心臓検査ができる」こと。手のひらサイズの高精度デバイスを数日間貼り付けるだけで24時間365日の心電図データを取得。独自のノイズカット＋AI・専門医による解析で、不整脈や睡眠時無呼吸症候群などの「隠れたリスク」を早期発見します。

2. 健康経営・ウェルビーイング支援

経営課題として注目される「健康経営」の一環として、企業向け福利厚生・定期検診オプションに導入が進む。突然死のリスクとなる心疾患を未然に防ぎ、従業員の健康と企業の生産性向上に寄与しています。

Participant 02

玉城 ミナホ

26カ国を旅した行動派・沖縄出身

意気込み

これまで行動力を武器に26カ国を旅し、さまざまな経験をしてきました。しかしその中で、「本当に自分がやりたいことは何か」「これからどんな生き方をしたいのか」を改めて考えるようになりました。 今回の企画では、志を持つ仲間たちとの出会いを通して、自分自身のこれからの方向性を見つけたいと思っています。また、同じ沖縄出身の参加者とも繋がりながら、「沖縄から世界へ」という想いをさらに広げていきたいです。

これまでの経験

これまで26カ国を訪れ、特に印象に残っているのがピースボートでの地球一周です。 その中で、ブラジル・サンパウロにある沖縄県人会を訪ね、現地で沖縄文化を守り続けるウチナーンチュの方々と出会いました。地球の反対側で沖縄の方言を聞き、一緒に三線を弾いた経験は今でも忘れられません。 この経験を通して、沖縄の文化やルーツへの誇りを改めて感じることができました。

この企画で得たいこと

私は将来、場所に縛られずに働く生き方に興味を持っています。特にSNS発信やSNS運用に関わる仕事に挑戦したいと考えています。 今回の企画では、実際に発信を続けている運営メンバーや参加者から学び、自分らしい働き方や生き方のヒントを見つけたいです。

参加者のみなさんへ

海外を旅して学んだのは、「行動した人にしか見えない景色がある」ということです。 今回も失敗を恐れず挑戦し、お互いの価値観や夢を共有しながら刺激し合える時間にしたいと思っています。この出会いが、みなさんにとっても人生の転機になることを楽しみにしています。
